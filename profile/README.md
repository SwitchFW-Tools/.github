# SwitchFW Tools 🛠️

Welcome to the official GitHub organization for **SwitchFW Tools**. We are a dedicated group of reverse engineers and developers building open-source utilities for the **Nintendo Switch 2**.

Our mission is to provide the community with safe, automated, and reliable tools for custom firmware (CFW) management and payload injection.

---

### 🚀 Our Projects

Explore our ecosystem of open-source tools:

* ⚡ **[Switch 2 Bootstrapper](https://github.com/SwitchFW-Tools/switch2-bootstrapper)**: The official web-based and PowerShell utility for automated USB-C payload delivery and CFW activation.
* 📚 **[Switch 2 Core Libraries](https://github.com/SwitchFW-Tools/switch2-core-libs)**: Core C++ development kit and memory hooking libraries for homebrew developers.
* 🔌 **[USB Payload Injector](https://github.com/SwitchFW-Tools/usb-payload-injector)**: Lightweight cross-platform utility for raw `.bin` payload injection.
* 📖 **[Switch 2 Homebrew Docs](https://github.com/SwitchFW-Tools/switch2-homebrew-docs)**: Reverse engineering notes, hardware analysis, and firmware teardowns.
